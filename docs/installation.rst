Installation
============

Quick Install
-------------

.. code-block:: bash

   git clone https://github.com/yashwankhede/Terminal_AI.git
   cd Terminal_AI
   chmod +x install.sh
   ./install.sh

Manual Installation
--------------------

.. code-block:: bash

   pip install -r requirements.txt
   python terminal_ai_cli.py --set-api-key YOUR_API_KEY

Requirements
------------

- Python 3.7 or higher
- OpenAI API key
- Internet connection
