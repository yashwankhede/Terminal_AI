# Changelog

All notable changes to Terminal_AI will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2025-01-XX

### Added
- Initial release of Terminal_AI
- Natural language to command execution
- Interactive mode with context awareness
- Multi-terminal support for parallel tasks
- Automatic subdomain/IP detection and /etc/hosts management
- Wordlist detection and automatic path usage
- Dangerous command detection with confirmation prompts
- Error-aware command generation with alternative suggestions
- Command history with readline support
- Secure API key storage
- First-run star prompt
- Comprehensive logging system
- Python package structure with modular design

### Changed
- Refactored from single-file script to proper Python package
- Improved error handling and user feedback
- Enhanced AI prompts with better context awareness

### Fixed
- Fixed msfconsole getting stuck issue
- Fixed typo detection for --interactive flag
- Fixed command not found error handling
- Fixed parallel terminal control system

## [Unreleased]

### Planned
- VSCode extension
- Plugin marketplace
- Auto-workflow builder
- Persistent memory profiles
- Enhanced documentation
